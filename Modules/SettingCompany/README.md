# SettingCompany Module

File composer.json:
```json
"require": {
        "goldenbeeltd-vn/settingcompany-module": "^1.0",
},
"repositories": [
    {
        "type": "vcs",
        "url": "git@github.com:goldenbeeltd-vn/settingcompany-module.git"
    }
]
```
Cập nhập lại composer:
```
composer update
```
