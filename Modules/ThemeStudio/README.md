# ThemeStudio Module v1

File composer.json:
```json
"require": {
        "goldenbeeltd-vn/theme-studio-module": "^1.0",
},
"repositories": [
    {
        "type": "vcs",
        "url": "git@github.com:goldenbeeltd-vn/theme-studio-module.git"
    }
]
```
Cập nhật lại composer:
```
composer update
```
